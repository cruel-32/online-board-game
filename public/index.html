    내 조합 어시스트

    조합을 누르면 해당 타일이 선택됩니다.

    게임룰

    목표

    자신의 타일을 가장 먼저 모두 내려놓으면 승리합니다.

    숫자·무늬 세기

    숫자는 3(가장 낮음) → 4 → … → 15 → 1 → 2(가장 높음) 순으로 강합니다.
    같은 숫자라면 무늬로 비교합니다: 구름 < 별 < 달 < 해.

    낼 수 있는 조합
    • 1장 : 싱글
    • 2장 : 페어(숫자가 같은 2장)
    • 3장 : 트리플(숫자가 같은 3장)
    • 4장은 낼 수 없습니다.
    • 5장 : 스트레이트 < 플러쉬 < 풀하우스 < 포카드 < 스트레이트플러쉬 순으로 강함
    진행 방법

    이전 사람이 낸 것과 같은 개수로 더 높은 조합만 낼 수 있습니다. 낼 수 없으면 패스합니다. 모두 패스하면 마지막으로 낸 사람이 선(先)이 되어 원하는 조합을 자유롭게 낼 수 있습니다.

    조합별 비교 방법
    • 싱글·페어·트리플 : 숫자를 먼저 비교하고, 같으면 무늬로 비교
    • 스트레이트·스트레이트플러쉬 : 구성 숫자를 먼저 비교하고, 완전히 같으면 무늬로 비교
    • 플러쉬 : 5장의 숫자를 높은 순서대로 차례로 비교하고, 5장이 모두 같을 때만 무늬로 비교
    • 풀하우스·포카드 : 트리플/포카드를 이루는 숫자로 비교
    '1'의 특수 기능

    스트레이트를 만들 때 가장 큰 숫자 다음(맥스+1)으로도 사용할 수 있습니다. 예) 5인전(1~15)에서 12,13,14,15,1도 스트레이트가 됩니다.

    '2' 페널티

    게임이 끝났을 때 손에 '2'가 남아 있으면 남은 타일 개수를 2배로 계산합니다. (2를 2장 가지고 있으면 4배, 3장이면 8배)

    칩 정산

    모든 플레이어 쌍마다 남은 타일 개수 차이만큼, 더 많이 남긴 쪽이 적게 남긴 쪽에게 칩을 지불합니다.
