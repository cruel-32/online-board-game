# 렉시오 온라인 개발 가이드
- 보드게임 렉시오를 온라인 게임으로 개발
- 게임의 룰은 game_rules 폴더에 이미지 형태로 저장

## 개발 스펙
- UI: html, css3, javascript, canvas
- BE: nodejs, redis, websocket, postgre
- etc: docker-compose로 띄워서 홈서버에서 서비스할 예정

## 필수 개발 요소
- 렉시오의 룰을 온라인으로 개발
- 기본적으로 스마트폰 가로모드로 플레이
- 게임대기룸을 생성하고 초대할 수 있는 기능 제공
- 플레이인원은 3~5인이지만 부족한 플레이 인원은 컴퓨터를 추가하여 플레이 가능
- 게임 대기룸에서 최대플레이 인원수를 조절하고 강퇴할 수 있는 기능 제공
- 허용된 인원만 게임을 할 수 있도록 게임 생성시 비밀번호 필요 기능 구현
- 칩 갯수는 모두 동일하게 최소 50개이고 방장이 50개 단위로 조절 가능
- 칩이 모두 소진된 인원이 생기면 게임 종료. 추후 방에 남아 있는 인원이 다시 준비하면 게임을 재시작할 수 있는 기능 추가
- 내가 가진 조합이 뭔지 보여주는 어시스트 기능 (버튼을 누르면 팝업형태로 띄워서 보여줌)

## UI 요구 사항
- 게임방에 입장한 사람들을 카지노 같은 장소에서 원형 테이블에서 플레이 하는 것처럼 입체적으로 구현
- 아이폰 se화면에서도 모든 게임 UI가 잘리지 않도록 구현
- 현재 선 플레이어가 누구인지 알기 쉽도록 구현
- 원형 테이블에 마지막으로 낸 패가 입체적인 3D 타일 형태로 구현
- 마지막으로 낸 패가 어떤 패인지, 누가 낸 패인지 잘 알 수 있도록 구현
- 본인의 패 타일을 오름차순으로 자동 정렬
- 추후 수동으로 드래그를 통해 정렬 변경 가능. 드래그 되는 패와 대체될 자리에 대해서도 액티브 효과 부여.
- 상대방의 남은 타일 수를 알기 쉽도록 구현 
- 현재 낼 수 없는 패와 낼 수 있는 패를 구분하여 표시
