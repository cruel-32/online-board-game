# 펠리시티 온라인 개발 가이드
- 보드게임 펠리시티를 온라인 게임으로 개발
- 게임의 룰은 해당 폴더에 이미지 형태로 저장

## 개발 스펙
- UI: html, css3, javascript, canvas
- BE: nodejs, redis, websocket, postgre
- etc: docker-compose로 띄워서 홈서버에서 서비스할 예정

## 필수 개발 요소
- 펠리시티의 룰을 온라인으로 개발
- 그 외에는 선 개발한 lexio와 유사한 기능제공

## UI 요구 사항
- 전체적으로 lexio와 유사한 UI/UX 및 레이아웃
