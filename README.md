# 보드게임 온라인 (Board Games Online)

여러 보드게임을 한 서비스에서 즐기는 온라인 멀티플레이 플랫폼입니다.
방을 만들 때 게임을 고르고, 대기실에서 방장이 언제든 게임을 바꿀 수 있습니다.

현재 지원 게임:
- **렉시오 (LEXIO)** — 3~5인. 손패를 먼저 모두 내려놓으면 이기는 조합 카드게임.
- **펠리시티 (자루 속 고양이)** — 4~5인. 9라운드 경매로 고양이 카드를 모아 최고 점수를 노리는 게임.
- **우노 (UNO)** — 2~6인. 손패를 가장 먼저 다 털면 승리하는 표준 우노 룰.
- **홀덤 (Texas Hold'em)** — 2~6인. 커뮤니티 카드 5장 + 블라인드 베팅. 한 명만 칩이 남을 때까지 여러 핸드 진행.
- **세븐포커 (7-card stud)** — 2~6인. 7장(비공개+공개) 중 최고의 5장으로 승부.
- **노땡스 (No Thanks!)** — 3~5인. 칩을 걸어 카드를 넘기거나 가져가며, 낮은 점수를 노리는 카드게임.
- **테트리스** — 2~4인. 실시간 배틀로얄. 2줄 이상 지우면 상대에게 가비지 공격, 최후 생존자가 승리.
  (서버가 물리까지 전부 계산하는 서버 권위 구현. 이전의 클라이언트 권위 구현은 비교용으로 코드베이스에는
  남아 있지만 사용자에게는 노출하지 않는다 — 두 구조의 차이는 `docs/ARCHITECTURE.md` 참고)

> 방/로비/채팅/음성/봇 같은 공용 기능 위에 게임별 규칙·UI를 플러그인으로 얹는 구조입니다.
> 새 게임 추가 방법과 전체 설계는 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)를 참고하세요.

## 실행 방법

### Docker (홈서버 배포)

```bash
docker compose up --build -d
# http://<서버주소>:8082 접속
```

앱(Node.js) + Redis + PostgreSQL이 함께 기동됩니다.
게임 결과는 PostgreSQL(`round_results` 테이블, `game_id` 포함)에 기록되고 Redis에 최근 결과가 캐시됩니다.

### 로컬 개발

```bash
npm install
npm run dev        # http://localhost:8080
npm test           # 규칙 엔진 단위 검증 + 봇 자동 대전 시뮬레이션
```

Redis/PostgreSQL 없이도 동작합니다. (`REDIS_URL`, `DATABASE_URL` 환경변수 설정 시 사용)

## 공통 기능

- **로비/대기룸**: 게임 선택 후 방 생성(비밀번호 선택), 초대 링크 복사, 방장 권한(게임 변경, 최대 인원 조절, 강퇴, 봇 추가/제거)
- **봇 플레이**: 인원이 부족하면 봇으로 채워 플레이 가능. 게임 중 이탈/접속 끊김 시 봇이 대신 진행
  (단, 테트리스는 실시간 대전 특성상 이탈 시 봇으로 전환하지 않고 접속이 끊기면 즉시 탈락 처리되며,
  대신 대기실에서 미리 추가한 봇은 서버가 자체 AI로 실시간 플레이합니다)
- **채팅 / 음성채팅**: 대기실·게임 화면 공용 위젯. 텍스트 채팅은 서버 중계, 음성은 참가자끼리 WebRTC로 직접 연결(P2P mesh)하며 서버는 시그널링만 중계.
  채팅 메시지는 보낸 사람 캐릭터 옆 말풍선으로도 잠시 표시됩니다.
  ⚠️ 마이크 접근은 브라우저 보안 정책상 HTTPS(또는 localhost) 접속에서만 동작합니다 — 홈서버에 도메인+TLS(리버스 프록시)를 붙여야 폰에서 사용 가능
- **효과음**: 합성 사운드 + 음성 안내(내 차례 등)
- **UI**: Canvas 렌더링, 가로/세로 모드 대응, 게임별 규칙 팝업(테트리스는 키 바인딩 설정 팝업)

## 게임별 특징

### 렉시오
- 인원별 타일 범위(3인 1~9 / 4인 1~13 / 5인 1~15), 구름③ 선, 1·2·3·5개 제출,
  스트레이트<플러쉬<풀하우스<포카드<스트레이트플러쉬, 특수 스트레이트 서열, '1'의 특수기능, '2' 검사(남은 타일 2배)
- 칩 정산: 시작 칩은 최소 50점(방장이 10점 단위 조절). 라운드마다 남은 타일 수 차이만큼 쌍별 정산.
  칩 소진자가 나오면 매치 종료 → 다시 준비하면 새 매치
- 카지노풍 원형 테이블, 입체 타일, 손패 자동/드래그 정렬, 낼 수 있는 패 구분 표시, 조합 어시스트, 오토패스

### 펠리시티
- 매 라운드 전원이 카드를 뒷면으로 놓아 "자루"를 만들고, 시작 플레이어 카드를 공개 후 경매
- 입찰/패스(패스 시 입찰 코인 회수 + 남은 최저 쥐 카드 코인 획득 + 카드 1장 공개), 최후 1인이 낙찰가를 내고 자루 획득
- 개(큰/작은)가 고양이를 쫓아내는 특수효과, 토끼(0점), 코인은 비공개
- 9라운드 후 모은 고양이 값 + 남은 코인으로 최종 점수 계산

### 우노
- 표준 우노 룰: 색깔/숫자 일치 또는 기능 카드(스킵·역방향·드로우2·와일드·와일드드로우4)로 진행
- 손패를 가장 먼저 모두 내면 승리. 코인 경제 없이 한 판이 곧 매치 — 결과 화면에서 "다시 하기"로 새 판 시작

### 홀덤
- 텍사스 홀덤 표준 룰: 스몰/빅 블라인드(10/20), 커뮤니티 카드 5장(플랍·턴·리버), 프리플랍부터 쇼다운까지 베팅
- 시작 스택 기본 1000칩(방장이 100 단위로 조절). 여러 핸드를 이어가며 한 명만 칩이 남으면 매치 종료

### 세븐포커 (7-card stud)
- 앤티를 낸 뒤 7장(비공개 2장+공개 1장으로 시작, 이후 공개 3장을 한 장씩 더 받고 마지막 7th는 비공개)
- 3rd~7th 스트리트마다 베팅, 최고의 포커 핸드 5장으로 승부. 여러 핸드 진행, 한 명만 칩이 남으면 매치 종료

### 노땡스 (No Thanks!)
- 3~35 중 9장을 제외한 24장의 카드를 한 장씩 공개하며 진행. 자기 차례에 칩 1개를 걸어 다음 사람에게 넘기거나,
  카드(+ 그 위에 쌓인 칩)를 가져감 — 가져가면 새 카드가 공개되고 다시 자신의 차례
- 점수 계산: 모은 카드 중 연속된 숫자는 가장 낮은 값만 합산, 거기서 남은 칩 개수만큼 차감(점수가 낮을수록 유리)
- 덱을 모두 가져가면 게임 종료. 한 게임이 곧 매치이며 봇은 지원하지 않음

### 테트리스
- 2~4인 실시간 배틀로얄. 다른 게임들과 달리 턴 개념이 없어 전원이 동시에 자기 보드를 플레이
- 2줄 이상 동시에 지우면 상대 중 한 명에게 가비지(방해줄)를 전송, 보드가 가득 차면 탈락, 최후 생존자가 승리
- 콤보(연속 클리어)·백투백(연속 테트리스) 보너스로 공격이 점점 더 커지며, 시간이 지날수록 전원의 낙하 속도도
  개인 성과와 무관하게 계속 빨라짐
- 서버가 전원(사람+봇)의 물리(중력·충돌·회전)를 직접 계산하는 서버 권위 구조. 클라이언트는 입력만 보내고
  서버가 계산한 상태를 그대로 받아 그림(자세한 구조와 클라이언트 권위 방식과의 비교는
  `docs/ARCHITECTURE.md` 참고)
- 키보드(WASD/방향키/JKL 등, "버튼설정" 팝업에서 자유롭게 재배정 가능)와 터치 버튼(방향키 배열 모양) 동시 지원
- 매치 시작 전 3·2·1 카운트다운. 대기실에서 미리 추가한 봇은 실시간으로 함께 플레이하지만, 사람 플레이어는
  이탈/접속 끊김 시 봇으로 전환되지 않고 즉시 탈락 처리

## 구조

```
public/shared/lexio-core.js       렉시오 규칙 엔진(서버·클라 공용)
public/shared/felicity-core.js    펠리시티 규칙 엔진(서버·클라 공용)
public/shared/poker-core.js       포커 핸드 평가 엔진(홀덤·세븐포커 공용, 서버·클라 공용)
public/shared/tetris-core.js      테트리스 조각 모양·회전·7-bag 시드 난수(서버·클라 공용)

server/src/index.js               HTTP + WebSocket 서버
server/src/rooms.js               방/로비/채팅·음성/봇 오케스트레이터(게임 독립)
server/src/games/registry.js      게임 엔진 레지스트리
server/src/games/<id>/            게임별 엔진(index.js) + 상태머신(game.js) + 봇(bot.js)
server/src/store.js               Redis / PostgreSQL 영속화(선택)

public/js/core/                   공용 모듈(net, modal, chat, widgets, shell, platform)
public/js/voice.js                WebRTC 음성채팅(P2P mesh)
public/js/sound.js                효과음(합성 사운드 + 음성 안내)
public/js/games/registry.js       게임 클라이언트 레지스트리
public/js/games/<id>/             게임 클라이언트(index.js) + Canvas 렌더러(ui.js)
public/js/games/tetris/engine.js  테트리스 보드 시뮬레이션(순수 로직). UMD라 서버·클라 양쪽에서
                                   그대로 require해 쓴다 — tetris-server는 서버에서, tetris(비노출)는
                                   클라이언트에서 이 엔진을 돌린다
```

턴제 게임(렉시오·펠리시티·우노·홀덤·세븐포커·노땡스)은 서버가 각 액션을 받아 상태를 갱신하고
전체 상태를 브로드캐스트하는 방식으로 동작합니다. 테트리스만 예외로, 턴 없이 전원이 동시에 진행하는
실시간 게임이라 서버가 각자의 물리(중력·충돌·회전)까지 직접 계산하고, 클라이언트는 입력만 보내
매 틱 브로드캐스트되는 상태를 그대로 그립니다(`server/src/games/tetris-server/`).
같은 규칙을 클라이언트가 로컬 시뮬레이션하고 서버는 결과만 심판하는 방식으로 구현한 버전도
`server/src/games/tetris/`에 비교용으로 남아 있지만, 현재 사용자에게는 노출하지 않습니다.

자세한 설계와 새 게임 추가 방법은 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)에 있습니다.
